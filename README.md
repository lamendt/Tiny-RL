A KiB-scale deck-building auto-battler rougelike for Linux.

Two versions, a completed <2KiB minimal (but still fun) version, and a planned fleshed out <4KiB version. Compresses with lzma when building and uses a shell header that decompresses on execution.

Features:
- Procedural card generation with interacting stats (Buffs, repeats, poison, etc.)
- Card selection and deck pruning
- Enemy decks and scaling
